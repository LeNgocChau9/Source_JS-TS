Tạo một form html gồm:
- Input nhập username
- Input nhập password
- Button "Đăng nhập"

- Lấy giá trị từ hai ô nhập liệu
- So sánh với username/password đã định nghĩa sẵn trong JavaScript (hardcode)
  username: Chau15072000@gmail.com
